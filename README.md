# Battery-AI-Saver-
O Battery AI Saver oferece monitoramento da bateria e automações de economia autorizadas pelo usuário. O aplicativo não exige conta, não integra anúncios, rastreadores publicitários ou serviço próprio de envio de diagnósticos. Os dados usados para suas funcionalidades são processados localmente no aparelho, sem envio automático ao desenvolvedor.
